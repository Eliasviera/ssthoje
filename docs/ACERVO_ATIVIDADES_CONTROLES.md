# Acervo de atividades, riscos e controles

Base planejada para APR, PT e mobilização de terceiros. O acervo serve para organizar informações e sugerir checklists; não decide risco, conformidade, aptidão ou liberação sem revisão humana.

## Cadastro por atividade ou tarefa

Cada item deverá ter versão, situação, responsável pela revisão, data de vigência e fonte ou política interna que o sustenta.

| Grupo | Informações a registrar |
| --- | --- |
| Atividade e tarefa | Nome, descrição, processo, local e escopo de aplicação |
| Equipamentos | Equipamentos, ferramentas e proteções exigidas |
| Riscos e perigos | Perigo, fonte ou circunstância, grupos expostos e possível dano |
| Treinamentos | Tema, carga horária, evidência exigida e aplicabilidade declarada |
| Medidas de controle | Eliminação, proteção coletiva, procedimento, EPI e responsável |
| 5S | Critérios internos de organização, limpeza, identificação e verificação |
| Documentos relacionados | PGR, APR, PT, O.S., treinamento, ficha de EPI e outros configuráveis |

## Uso no sistema

1. A consultoria seleciona atividades aplicáveis ao escopo.
2. O sistema sugere itens do acervo para conferência.
3. O responsável confirma, ajusta ou descarta cada sugestão.
4. APR, PT e relatório de mobilização guardam o retrato dos itens usados naquela versão.

Cada cliente poderá adotar somente as partes do acervo que fizerem sentido para seu contrato e sua política de rigor.
